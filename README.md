# Rhoodstone Mission — Premium Frontend

## Included
- Premium responsive landing page
- Project cards
- 24-hour countdown UI
- X connect modal (demo)

## Deploy
Upload `index.html`, `style.css`, and `app.js` to GitHub Pages, Netlify, Vercel, or your preferred static host.
